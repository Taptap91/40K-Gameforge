Add a faction PDF

Choose a faction PDF (for example a Wahapedia faction page saved as PDF). The app turns it into clean datasheets, detachments, enhancements and stratagems with exact points — and you can export it as a small Excel file.

How to save a Wahapedia page as a PDF
  1. Open the faction's page on Wahapedia (11th edition).
  2. Press Ctrl+P (Windows) or Cmd+P (Mac). On iPhone: Share › Print, then share the preview.
  3. Choose Save as PDF, paper size Letter or A4, and tick Background graphics.
  4. Save, then choose that file here.

Add from a web address

Paste a direct link to a rules PDF or web page. Some websites don't allow this — if so, save the page as a PDF and add it above instead.
