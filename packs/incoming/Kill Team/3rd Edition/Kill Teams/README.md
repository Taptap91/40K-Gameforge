Drop a Kill Team 3rd Edition kill team PDF here, one team per file, either directly in this folder or in a subfolder named for the team:

    Kill Teams/Nemesis Claw/Nemesis Claw.pdf

Every file here goes to the "Kill Teams" section of the Kill Team game pack, not to the 40K-style factions. Optional sidecar `.json` beside the PDF:

    { "group": "Chaos" }

`group` is Imperium, Chaos or Xenos, the toggle the app shows. Leave it out to fall into Xenos. A PDF without PDF Studio tags converts to a plain-text entry only; tag it in PDF Studio to get the datacards.
