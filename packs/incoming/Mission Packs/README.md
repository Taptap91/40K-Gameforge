Mission deck PDFs (Chapter Approved–style) go here — e.g. `chapter-approved-2026.pdf` +
`chapter-approved-2026.json`. `kind` is ignored for these; a mission pack is detected automatically from
the PDF's own contents. See `packs/incoming/README.md` for the sidecar format. This folder is just for
your own organization; the conversion workflow scans every subfolder here the same way.
